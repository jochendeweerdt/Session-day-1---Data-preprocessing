## Data

- `data/churn_sample.xlsx` – the 36-row excerpt of the I2A in-class exercise.
- `data/churn.csv` – 5,040 synthetic customers with the same columns plus `minutes_used_two_months_ago`
  (generated with `tools/make_churn.py`; planted issues: leaky columns, structural missingness,
  inconsistent formats, invalid and valid outliers, 40 duplicates, a high-cardinality postal code).
- `data/housing.csv` – the artificial housing dataset of the I2A EDA exercise (`;`-separated).
- `data/creditcard_sample.csv` – all 492 frauds and 30,000 random legitimate transactions of the
  credit card fraud dataset by Dal Pozzolo et al. (2015), ULB Machine Learning Group, made available
  on Kaggle under the Open Database License (ODbL). Created with `tools/make_creditcard_sample.py`.
